# Contributing

Thank you for helping. Bug reports, ideas and pull requests are all welcome.

## Before your first pull request

**Sign the Contributor License Agreement (CLA).** A bot asks you to on your first pull request. It takes one click. Beamlynx is offered under the AGPL and under a commercial license, and the CLA is what lets your contribution be part of both. You keep the copyright to your work.

## Finding your way

- What each folder holds, and the rules that span them: [`AGENTS.md`](AGENTS.md)
- Running the app from source: [`desktop/DEVELOPMENT.md`](desktop/DEVELOPMENT.md)
- Working on Pine, the query language: [`pine/AGENTS.md`](pine/AGENTS.md)
- Working on the interface: [`ui/AGENTS.md`](ui/AGENTS.md)

## A good pull request

- Does one thing, and says what and why in its description.
- Changes every folder it needs to. A Pine feature, the UI for it, and the agent docs for it belong in one PR.
- Adds a line under `## [Unreleased]` in the `CHANGELOG.md` of each folder it changes, written for someone who uses the app.
- Passes CI.

## Reporting a security problem

Please don't open a public issue. Write to contact@grephyte.com.
